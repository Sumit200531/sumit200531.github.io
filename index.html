How I work

I like problems where the data is messy and someone is waiting on the answer: crowd reports that lie, policy PDFs that bury the one rule that matters, traffic that has to be turned away fairly.

Day to day I write JavaScript and TypeScript with React, Node and Express, and Java with Spring Boot. Data goes into MongoDB, MySQL or Redis. For AI work I build retrieval pipelines: embeddings, vector search, BM25 and fusion, with Gemini or OpenAI behind them. I've also written C++ for systems work and PHP for the gateway, and I ship things in Docker with tests around the parts that matter.

Right now I'm getting sharper at data structures and algorithms, Spring Boot, system design and deployment.
