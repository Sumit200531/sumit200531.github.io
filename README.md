# portfolio

My personal site: [sumit200531.github.io](https://sumit200531.github.io)

Plain HTML, CSS and JavaScript, with no framework and no build step.

- the hero is a 3D ring of projects you can drag around (CSS 3D transforms)
- each project gets a layered drawing that tilts with your cursor
- "Also on GitHub" pulls my other public repos live from the GitHub API

## Editing

Everything personal is in `js/projects.js`: name, links, email, and the project write-ups.
Add a project there and it shows up in the ring and the case studies automatically.
The drawings are in `js/art.js`.

## Run locally

Open `index.html` in a browser.
